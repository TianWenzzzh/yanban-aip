# measure-20260924r — probe_ref_precision.py（轮 134 基线：参考文献的 precision 维度有没有对象）

## 它量什么
线上 49 份带 `[n]` 角标的报告、383 条列出的参考文献，逐篇算两个数：
- **挂了几次角标**：用产品自己的 `_CITE` 正则数（不另写一条正则，否则尺子与产物会各说各话）；
- **真撑住几句**：`evidence.grounding_report` 逐句台账里落在该篇的片段数（零模型调用）。

## 判据（跑前写死）
- 不变量 `sum(supports) == grounded + misnumbered` ⇒ 台账与汇总同源，两边各算一遍就会打架；
- 与 g116/g117 对账（754 项目 / 49 份报告 / 596 句 / true_gap 69），任一项不符 ⇒ RC=2 不出数；
- `_CITE.pattern` 与线上那份产品不一致 ⇒ RC=2（复刻产品逻辑的探针换形后会印幻影读数）；
- P2（挂了角标却一句都没撑住 = 假引用）≥ `LINE=0.10` ⇒ 这一维有对象，值得做进产物。
