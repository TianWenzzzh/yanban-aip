## 这一台答什么问题

「该挂来源却一处没挂」——g92 那把尺（`probe_citation_gap.py`）的分子只数**已经挂了角标的句子**，
它答不了"没挂"。这一台按产品同一套口径（`[n]` / `【n】` / `《论文》`）数零引用回复，
并且**把分母拆成"全部回复"与"当轮论文卡非空"**：不拆开，池子为空会被算成模型偷懒。

## 它产出的数（预登记的基线就是这两行）

- 全部回复 n=10：零引用 6 = 60%，平均带角标句 1.00 条/回复
- 有论文卡 n=6：零引用 2 = **33%**，平均 1.67 条/回复 ← 闸门 `no_citation` 的靶子

⚠️ 同一个脚本里两个口径并存，别读串：`零引用` 用宽口径（含《》，与闸门一致），
`逐条`/`平均` 是窄口径（只数句末 `[n]`）。所以「零引用 2」与「逐条里有 3 个 0」不矛盾。
