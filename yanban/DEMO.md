# 研伴系统 · 5 分钟评委演示脚本（2026-09-18 工作台版）

> 一键准备：`cd code/yanban && bash demo.sh`（栈未起则自动拉起 → 7 端点探活 → 自动提交一条演示任务）。
> 打开工作台：**http://localhost:8041/**（Leader 单端口静态托管新版 UI；8090 为 Vite dev；/ui 为旧版兜底）。
> 手动起栈（备查）：`run_all_partners.py` + `uvicorn gateway.partner:app --port 8021`（../mcp-aip-gateway）+ `uvicorn leader:app --port 8041`。

## 0. 开场（30 秒）——工作台空态

**镜头**：工作台首页（截图 docs/screenshots/20260918/p2_01_empty.png）。

**讲稿**：研究生做科研要切换检索、实验、写作、审稿一堆异构工具。研伴 = 基于 AIP 国标（GB/Z 185）
的科研协作多智能体系统：您用一句话说出研究想法，剩下的交给我们——全过程在右侧流水线实时可见。

## 1. 引导式下发（45 秒）——三步向导

**镜头**：向导第 1 步输入「论文全流程：主题：多智能体协作提升科研效率」→ 第 2 步（可跳过）→ 第 3 步确认提交。

**讲稿**：三步向导把自然语言变成结构化任务；引导语是前端常量，不花一次模型调用。
提交后 Leader 先做意图分解——命中 SOP 模板时直接生成确定性 DAG（结构化契约抑制幻觉）。

## 2. DAG 流水线可视化（75 秒）——灵魂画面

**镜头**：右侧流水线面板（p3_01_running.png → p3_02_completed.png）。

**讲稿**：文献 → 实验 → 写作 → 审稿四个阶段按依赖关系执行，上游产出自动注入下游：
实验方案引用文献清单、论文草稿编号引用 [文献N]、审稿人审的是真实草稿。每张阶段卡有
Partner 名、实时状态徽章、耗时、跨智能体 RPC 次数——全部来自 GET /task/{id} 原始 JSON，零编造。

## 3. 质量闭环（60 秒）——审稿人说了算

**镜头**：流水线下方「质量闭环」轮次时间线 + 报告区「修订说明」引用块。

**讲稿**：聚合报告会交给模拟审稿 Partner 走 AIP 协议评审，大修/拒稿自动触发修订再重审，
最多 3 轮——本条任务真实跑了 3 轮「拒稿→修订」，最终判定诚实展示（拒稿就是拒稿，不美化）。
对照实验：Best-of-2 选优 9.8 分 > 强模型重写 9.2 > 单 Agent 8.1 > 无闭环 4.9（数据概览页可看）。

## 4. 真实数据概览（45 秒）——诚实指标

**镜头**：左侧栏「数据概览」（p4_01/p4_02）。

**讲稿**：四指标卡（Task Completion 90%、Partial 100%、RPC 90%、Coverage 92%）由 Leader 只读端点
实时解析 bench-results-20260917.md 返回——每个数字可指出来源文件。下方对抗样例表讲述我们如何被
自己的指标逼着变强：首轮 TaskCompletion 0% 被当场揭穿 → 超时双修复 → 90%。

## 5. 双协议面演示（45 秒）——同一能力，两种协议，一个结果

**镜头**：「协议演示」页点「运行双协议演示」（p5_01）。

**讲稿**：同一个文献检索能力，左边走 AIP 国标 Direct RPC（POST /rpc），右边走 A2A
（AgentCard 发现 + tasks/send），两面结果逐字一致——这正是万桥互操作基准 D2「全回环」语义的
可视化。下方 AMP 审计尾巴滚动展示最近调用方/动作/耗时/结果码，全部真实落盘可回溯。
